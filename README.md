# TravelLoop ✈️

TravelLoop is a full-stack travel planning web application built using Angular, Node.js, Express, and MySQL.

## Features

- User Authentication
- Create Trips
- Edit Trips
- Delete Trips
- View Trip Details
- Image Support
- Responsive UI
- Dark Mode

## Tech Stack

### Frontend
- Angular
- TypeScript
- HTML
- CSS

### Backend
- Node.js
- Express.js

### Database
- MySQL

## Installation

### Frontend

```bash
npm install
ng serve
```

### Backend

```bash
npm install
node server.js
```
